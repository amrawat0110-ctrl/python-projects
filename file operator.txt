# 📌 Project Description

**Personal Journal Manager** is a menu-driven Python application that allows users to securely maintain a personal digital journal. The application enables users to add journal entries with timestamps, view all saved entries, search entries using keywords or dates, delete all journal records, and manage their journal through a simple Command Line Interface (CLI). The project demonstrates Python File Handling, Exception Handling, Object-Oriented Programming (OOP), and Date & Time modules. :contentReference[oaicite:0]{index=0}

---

# ✨ Features

- 📝 Add New Journal Entry
- 📖 View All Journal Entries
- 🔍 Search Entries by Keyword or Date
- 🗑 Delete All Journal Entries
- ⏰ Automatic Date & Time Stamp
- 📂 File Handling using Text File
- ⚠ Exception Handling
- 📋 Menu Driven Program
- 🚪 Exit Program

# 📥 Installation

### Step 1
Install **Python 3.x** from:

https://www.python.org/downloads/

### Step 2
Download the project file:

```
python project 6.py
```

### Step 3
Open **Command Prompt** or **Terminal**.

### Step 4
Navigate to the project folder.

### Step 5
Run the project using:

```bash
python "python project 6.py"
```

---

# ▶️ Usage

Run the program and choose an option from the menu.

```
1. Add a New Entry
2. View All Entries
3. Search for an Entry
4. Delete All Entries
5. Exit
```

Follow the on-screen instructions to manage your personal journal.
