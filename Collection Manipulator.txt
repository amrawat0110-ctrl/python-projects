# 📘 README.md - Student Data Organizer

## 📌 Project Description

**Student Data Organizer** is a menu-driven Python application designed to efficiently manage student records. The program allows users to perform essential operations such as adding new students, viewing all student records, updating existing student information, deleting student records, and displaying the list of subjects offered. This project demonstrates the practical implementation of Python data structures such as dictionaries, lists, and sets while providing a simple Command Line Interface (CLI) for user interaction.

---

## ✨ Features

- ➕ Add Student Records
- 📋 Display All Students
- ✏️ Update Student Information
- ❌ Delete Student Records
- 📚 Display Subjects Offered
- 🚪 Exit the Program

---

## 🛠 Technologies Used

- Python 3.x
- Dictionary
- Lists
- Sets
- Command Line Interface (CLI)

---

## 📥 Installation

1. Install **Python 3.x** on your computer.
2. Download the project file:
   ```
   python project 3.py
   ```
3. Open **Command Prompt** or **Terminal**.
4. Navigate to the project folder.
5. Run the program using:

```bash
python "python project 3.py"
```

---

## ▶️ Usage

After running the program, the following menu will appear:

```
1. Add Student
2. Display All Students
3. Update Student Information
4. Delete Student
5. Display Subjects Offered
6. Exit
```

Select an option by entering the corresponding number and follow the on-screen instructions to perform the desired operation.
